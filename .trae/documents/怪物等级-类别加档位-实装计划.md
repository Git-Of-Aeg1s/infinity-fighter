# 怪物等级（类别+档位）实装计划

## Context

为刷新波次重构打基础：给每个怪加入「等级」属性，格式 = **类别数字 + 类内强度档字母**（如 `3A`、`4C`），档位范围 **A~F**，A 最弱。
- 类别沿用现有 1~4 类分级（1虚象/2具象/3真我/4诗篇），与 `ENEMY_CLASS`（js/01-config.js L766-776）对齐
- 「倾向生成轮次」**不进等级**——那是波次编排数据，归将来的波次表
- 本次只做「标注 + 图鉴展示」，不改波次逻辑

**用户钦定值**：主力舰三色（capital_crimson/azure/crgold）= `4A`；法术阵列 = `4B`；战争幽灵 = `4C`；赤红炮艇 = `3A`（gunship 五色同档）。

## 改动 1：js/01-config.js 新增权威表

在 `ENEMY_CLASS`（L776）之后新增顶层 `ENEMY_GRADES` + 查询函数：

```js
// 怪物等级（类别+类内强度档 A~F，A 最弱）：key = 图鉴条目 id（与 ENCY_DATA 键一致），
// 类别位必须与 ENEMY_CLASS 对应类型一致（ENEMY_CLASS 为 type 粒度、本表为条目粒度）。
// BOSS（长歌级）/ 卫护飞船 escort / 龙卷 tornado 等衍生条目不设等级（无 key，图鉴自动不显示）。
const ENEMY_GRADES = { ... };
function enemyGrade(entryId) { return ENEMY_GRADES[entryId] || null; }
```
