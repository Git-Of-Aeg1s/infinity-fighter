# 大无垠战机 · Big Infinity Fighter

> 当前版本：**v0.3.4**（**成就系统上线：结算页徽章展示 + 数值图鉴「成就」页 + 27 个成就实装**；完整变更见文末「更新日志」）

一个纯前端（HTML5 Canvas + 原生 JS ES modules）实现的雷霆战机风格小游戏 Demo，无任何外部依赖。

## 快速开始

自 v0.2.6 起游戏脚本改为 ES modules 加载，`file://` 双击打开会被浏览器 CORS 策略拦截，必须通过 HTTP 访问：

- **双击 `启动游戏.bat`**（Windows）：自动启动本地服务器并打开浏览器，关闭窗口即停止服务器；
- 或手动启动静态服务器后访问 `http://127.0.0.1:8765`：

```powershell
# PowerShell
python -m http.server 8765 --bind 127.0.0.1
# 注：不要用 5173，该端口与其它服务冲突；localhost 可能解析到 ::1，故显式绑定 127.0.0.1
```

推荐 Chrome / Edge。开发期校验：`npm run check`（顶层命名/import-export 契约静态检查）、`npm run smoke`（无头跑帧冒烟测试，无需浏览器）。

## 操作说明

| 按键 | 作用 |
|------|------|
| `W` / `A` / `S` / `D` | 上 / 左 / 下 / 右 移动战机（也支持方向键） |
| `Space` | 释放高能爆弹：立刻清除全部敌弹 + 对全场敌人造成巨大伤害（4000 + 目标最大血量10%，真实伤害），附带白闪与震屏 |
| `F` | 释放装甲技能（七日澜心量表满后） |
| `Q` | 释放驾驶员技能（天秀忧郁王子量表满后：友方大风暴 / 陵落冷却结束后：强行暴走） |
| `8` | 连发风暴开关（装备天秀忧郁王子时可用）：战斗中切换——每 0.4~1.4s 自动向前发射一个友方大风暴（无视量表；期间发出的风暴向上移速 +80%），再按关闭 |
| `9` | 导弹雨连发开关（装备大狗时可用）：战斗中切换——导弹雨间隔 10~22s → 0.2~1s，再按恢复 |
| `0` + `1~5` | 武器等级切换：先按 `0` 武装（右上角音量键微微提亮为标识，任意界面可按），再按 `1~5` 直接设定火力等级（Lv5 即暴走） |
| `Shift` | 马兴犬：切换加速移动 ×1.25（再次点击恢复原速；装备马兴犬时可用） |
| `CapsLock` | 马兴犬：切换减速移动 ×0.8（再次点击恢复原速；装备马兴犬时可用） |
| `P` | 暂停 / 继续 |
| `R` | 立即重开 |

## 玩法要点

- **难度切换**：主界面可选**具象 / 真我 / 诗篇**三档难度（`DIFFICULTIES` 注册表驱动，各难度差异经 `mods` 修正表落地，三档均已实装）。**具象**——轻松难度，适合新玩家（休闲减负：总刷怪量/同屏约 -50~60%、攻击更稀疏、BOSS 伤害 -40% 且不连发同技能、导弹固定 50 伤害、受击不掉火力等，详见更新日志 v0.3.0）；**真我**——挑战难度，适合飞机老资历（**基准难度**，波次刷新间隔 ×1.3 微减负）；**诗篇**——直面疯狂（BOSS 血量 ×1.6、暴走伤害减免、BOSS 战 1类强制波、旧日之歌 / 暴风之眼技能组深度改版、**加血套件 8s 节流**、得分 ×1.2——详见更新日志与数值与机制图鉴「特殊机制」页）。图鉴头部可快捷切换难度（三选一按钮组）；HUD 左上角显示当前难度。
- **主菜单（独立页面）**：开始界面为全屏独立菜单页（星海背景持续流动）——大标题 + **难度 / 战机 / 僚机 / 装甲** 四组选择卡片 + 「开始游戏」按钮与 怪物图鉴 / 数值图鉴 入口；进入战斗后整页隐藏，暂停 / 失败 / 胜利结算仍走遮罩卡片。
- **选机页面**：主菜单展示战机卡片，选择后点“开始游戏”；当前可选 **混乱将至**（直射窄弹道）与 **群星之杀**（锁定光束 + 空间斩击、高额爆发，**默认机型**）。
- **副武器系统**：主菜单可选**副武器**（`SUB_WEAPONS` 注册表驱动，卡片自动生成）：**标准挂架**（默认，无效果）/**燎原双翼**（两翼斜射弹）/**贯川重炮**（机腹大口径重弹，可穿透 2 个敌人，穿透后伤害减半）/**追魂导弹**（双发限角速度追踪）/**无界飞剑**（尾部下沉 → 分裂多把飞剑前射，概率穿透）/**极夜飞星**（追踪激光弹，对 4 类敌人 +50%）/**捣蛋来袭**（直射导弹，Lv5 扇形三发）/**辛国栋之怒**（锁定场上血量最高敌人的持续灼烧火环）。与主炮独立冷却、同时自动开火；燎原/贯川/追魂按火力等级取参，其余固定参数。详细数值见数值与机制图鉴「副武器」页。
- **装甲系统**：主菜单可选**装甲**（`ARMORS` 注册表驱动，卡片自动生成，**注册表键序=展示顺序**：群星守望/铜皮夏勇/祈星/洄 → 七日澜心/最终壁垒/天枢圣卫/澄月 → 炽心 → 标准护甲（无效果自限选项））：**群星守望**（**默认**，对新最无脑直观）——击杀 1/2/3/4 类敌人时，有 5%/8%/15%/50% 立刻清除一颗离自身最近的敌方子弹（淡黄光粒连线演出）；**BOSS 战期间**概率统一为 40%，且改为清除该敌人发出的所有在场射弹（多束粒子光束齐射演出）；**诗篇以下难度（具象/真我）清除概率 ×1.5（上限 100%）**；**铜皮夏勇**——血量提高 30（100 → 130）；**祈星**——受到伤害时 30% 概率伤害减半，单次伤害 >40 时概率提升到 60%；**洄**——每 2 秒恢复 1 生命，击败 BOSS 时回复 35% 已损失生命；**七日澜心**——左下角圆形计数表随收集水晶填充（**按水晶得分等比**：普通 +10、巨型 +500，**5000 分填满**；首轮 BOSS 掉落的水晶对量表收益 **+700%**；**BOSS 战期间击杀敌人直接充能 1%~3%**），按 F 触发：结晶护盾（量子护盾样式+晶体网格，#FFC0CB）环绕自身 **4.8s**（期间量表停计），消失时清除周围 250px 内所有敌弹并发出小范围冲击波（技能走通用量表框架 `ARMOR_SKILLS`，后续可扩展）；**最终壁垒**——每条命一次：生命值减为 0 时不死（同样生效于导弹等强制击杀），恢复 1 点生命、获得 3s 无敌（淡金菱形环绕机体、不闪动，**无敌期间射速 -50%**），菱形消散时清除周围 250px 内所有敌弹并扩散金环；**天枢圣卫**——从所有来源获得的无敌时间 +60%，无敌期间免疫破片导弹的"无视无敌"穿透；**每 20s（无敌结束后起算）展开持续 10s 的「圣守窗口」**：窗口内受到伤害时在结算前触发无敌（常规受击无敌时长），该次伤害完全免除；窗口期间与无敌期间周期均不计时，窗口关闭或触发消耗后重新计时（等效 30s 一轮；重生 / 重开重置）；**澄月**——触发暴走（含续时）时 15% 概率获得量子护盾，BOSS 战中概率提升到 50%（每个 BOSS 最多一次），护盾时长与量子护盾一致（6s）；**炽心**——自身环绕焦香同款火环（半径 108、整体减淡、低图层绘制不遮挡任何单位），免疫焦香火环伤害与寒霜减速，火环持续灼烧周围敌人（每 0.125s 10 伤害，**对灰色 / 黑色标记敌人 +50%**——灰黑系特殊无人机/炮兵、幽暮与黑色 BOSS，见颜色标记系统，虚化敌人除外）。主菜单装甲卡片展示简短文案（`brief`），详细数值统一收录于数值与机制图鉴「护甲」页（`desc`）。
