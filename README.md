# 大无垠战机 · Big Infinity Fighter

> 当前版本：**v0.2.0**（完整变更见文末「更新日志」）

一个纯前端（HTML5 Canvas + 原生 JS）实现的雷霆战机风格小游戏 Demo，无任何外部依赖。

## 快速开始

直接双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge）。

如需本地服务器：

```powershell
# PowerShell
cd D:\develop\Codes\infinity_fighter
python -m http.server 8765 --bind 127.0.0.1
# 然后浏览器访问 http://127.0.0.1:8765
# 注：不要用 5173，该端口与其它服务冲突；localhost 可能解析到 ::1，故显式绑定 127.0.0.1
```

## 操作说明

| 按键 | 作用 |
|------|------|
| `W` / `A` / `S` / `D` | 上 / 左 / 下 / 右 移动战机（也支持方向键） |
| `Space` | 释放高能爆弹：立刻清除全部敌弹 + 对全场敌人造成巨大伤害（4000 + 目标最大血量10%），附带白闪与震屏 |
| `P` | 暂停 / 继续 |
| `R` | 立即重开 |

## 玩法要点

- **选机页面**：标题页展示战机卡片，选择后点“开始游戏”；当前可选 **混乱将至**（直射窄弹道），更多战机待接入。
- **主炮自动开火**，火力分 5 级，拾取粉色 `↑` 升级套件提升。
- **生命**：初始 2 条命，每条命 HP 100；血量归零掉一条命（重生后火力重置 Lv1），两条命都没了游戏结束。
- **HUD**：左上角 SCORE 面板 + 关卡 / 高能爆弹；左下角 HP 条 + 生命（♥）；右下角暴走 / 护盾倒计时读条（颜色区域随剩余时长逐渐变短）。
- **水晶**：击坠敌机大概率掉落数量不等的水晶（体型越大概率越高），垂直下坠不乱飘；每颗 +10 分，普通水晶有 0.4% 概率变为紫色**巨型水晶**（体型稍大，+500 分，相当于 50 颗）；飞机有磁吸能力，靠近自动吸附。
- **量子护盾**：击落敌机 2.5% 概率掉落青色 `◇`；拾取后 8 秒护盾加持——敌弹碰到护盾气泡即消解、免疫碰撞伤害（相当于无敌），护盾解除时清除场上一切敌弹。
- **判定点**：战机只有机身中心一个小判定点（发光白点，位于中心略下 4px），子弹 / 敌机直接命中该点才扣血，擦机身不算。
- **火力等级**（混乱将至：纯直射，攻击宽度始终控制在机身范围内，弹速快）：
  - Lv1 三射线（射速稍慢）→ Lv2 四射线 → Lv3 五射线（射速正常）→ Lv4 五射线 + 半拍后于中间补射 2 发（视觉错开，不增宽）
  - **Lv5 即暴走（限时 6s）**：十射线金色弹体（主弹 + 尾随暗弹双连发）+ 机身暴走光环，抵达时机身上方浮现“暴走”字样；暴走期间**攻速与 Lv4 相同（不再提升）、弹速大幅提升**，6s 后自动回落 Lv4（右下角读条显示剩余时长）
  - 非暴走（Lv1~Lv4）被击中：除了扣血，**累计受击两次才掉一层火力等级**（每掉一层重置计数）；**暴走（Lv5）被击中不掉层数也不计数**（护盾期间同样免疫）
  - **进入 BOSS 战会重置受击计数，且放宽为累计受击 3 次才掉一层火力**；**火力 Lv1 时对 BOSS 的武器伤害 +20%**（逆境补偿，高能爆弹不受影响）
- **HP 100**：受击后有 1.2s 无敌闪烁，不同敌机伤害不同。
- **四类敌机**：

  | 类别 | 名称 | 入场方式 | 血量 | 攻击行为 |
  |------|------|---------|------|---------|
  | 1类 | 侧翼艇（三色变体） | 从场地中部略偏上的两侧斜插窜出（速度×0.6），**最少 3 个一组**、编队形态随机（纵队/斜线/横排梯队/V字） | 极低（一碰就碎） | 依行为上色：**白**＝无攻击斜插穿越（70%）；**黄**＝追踪射击（10%）；**紫**＝亡语垂直射击（20%） |
  | 2类 | 突击艇（红/橙/蓝/白变体） | 上方入场，前锋线短暂停顿后向下冲锋（速度×0.7） | 低 | **赤红**＝垂直直射、±10° 偏差、不追踪，初次发射 +1s（30%）；**烈橙**＝朝前方对称射两发（夹角 50°/60°/70° 随机），无初次发射修正（30%）；**幽蓝**＝追踪玩家射击、初次发射 +1s，登场 10% 概率 1s / 10% 概率 2s 虚化护盾（25%）；**霜白**＝不开火，到位停留 2s 再冲锋（15%） |
  | 3类 | 炮艇（多色变体） | 上方**快速**入场，悬停很久后缓慢下压 | 中 | 常规子弹为**橙红色长条弹**。**紫**＝正下方同向双连射(2发、间隔小)/8发环形/追踪±5°双弹(同时2发)/追踪狙击 循环；**红**＝瞄准三连射 → 左右同时双曲线弹流(每侧6发、向两侧外扩) → 三方向四轮齐射(下与下±20°、每向2发×4轮)；**金**＝`/\/\`弹幕(竖直夹角10°、快发2次、短暂间隔后再快发2次) → 单发巨型弹(常规橙红配色、半径-30%、仅1发) |
  | 3类(特殊) | 炮火先兆者（灰黑体+红核） | 上方**极慢**入场（比 2 类还慢、无 3 类高速加成），悬停位置更靠上（后排） | 中 | 不直接开火：就位后核心红色从中心扩展，3s 充满即**召唤导弹**（最多导引 4 次），随后 2s 灰黑从中心覆盖，循环；碰撞伤害仅为 2 类的 50% |
  | 4类 | 主力舰（多色变体） | 居中**快速**入场（占半屏宽），悬停很久后缓慢下压 | 高（对 Lv4/暴走 火力减伤 15%） | 常规子弹为**橙红色长条弹**。**红**＝双翼交叉矛(发射点上移、下方更散) / 双曲线宽扇(一侧6发递增弯向斜下、覆盖极广，短暂间隔后另一侧、先左先右随机) / 加速弹幕(先 `/||\` 后 `/|\`，每笔画4发、间距更大，初速极低→加速到常规弹速2倍、加速时间更长) 循环；**蓝**＝瞄准六连齐射(±20°随机偏差) / 淡橙红大弹飞行较短段后短时减速到0并分裂6小弹(互相60°) / 双臂螺旋12发；出场及在场期间由 1/2 类护航 |
  
  - **3/4 类变体**：每次出场随机选取一种变体（颜色不同、技能不同）。其中**蓝色 4 类**出现时有 **20% 概率带护盾**：**前 6s 处于虚化状态**——机身半透明、不受任何伤害（含高能爆弹），**我方炮弹会穿过护盾打到它后面的敌人**；6s 后虚化结束方可被击破。

  - **停留与开走**：3/4 类及炮火先兆者就位后会原地开火一段时间，随后**停止攻击、以与进场相同的速度向下开走**（可能撞击我方战机）。开走计时从**就位**起算：**3 类＝30s、4 类＝40s、炮火先兆者＝18s**（约导引 4 次导弹后开走）。

  - **炮火先兆者导弹**：召唤时先锁定玩家当前水平位置，生成一条**垂直的红↔橙闪动预警线（带顶部警告图标）**；**3s 后**一枚**宽于常规子弹**的导弹从屏幕上方高速垂直下落。命中判定：**玩家 HP < 60 → 直接击杀**；**HP ≥ 60 → 失去 80% 当前血量 + 武器等级 -1**（量子护盾可消解导弹，高能爆弹可清除预警线与导弹）。

- **特殊编队**（Lv2 起约 40% 波次触发，对称/非对称混合）：
  - **镜像横排 232232**：左右对称的一排敌人（回文序列，两个 3 类移动稍慢）
  - **侧翼斜扫长队**：1 类长队从一侧斜扫到较靠下的另一侧（左右对称交叉）
  - **V 字俯冲**：2 类组成对称箭头/V 字从上方俯冲
  - **双炮艇压阵**：左右各一艘 3 类对称悬停，中间 2 类护航
  - **对角奇袭**（非对称）：一列混编沿对角线从一个上角斜插入场（1 类三个一组）
  - **紫自爆流**：左右两侧各依次出来七个 1 类紫（kamikaze）成纵列斜扫穿越，阵亡亡语向下垂直射一发

- **出场节奏**：1/2 类按波次循环出场，**上一波的机动兵力（1/2 类）完全清场后才放下一波**，避免波次重叠；Lv2 起 3 类按冷却出场（同屏限 1；**本局首次必定为后排“炮火先兆者”**便于识别，之后约 **30%** 为先兆者、否则普通炮艇）；Lv3 起 4 类主力舰按冷却出场（同屏限 1）。
- **关卡推进**：每 1500 分升一级，敌机 HP、生成频率递增。
- **道具掉落**：击落敌机掉落（12% 套件 / 2.5% 护盾 / 2.4% 加血套件）；**高能爆弹不在通用掉落池**，仅击败 4 类主力舰（7%）与 BOSS（25%）掉落
  - **动态降率**：当「场上升级套件数 + 我方当前攻击等级」等于 4 时，升级套件掉率减半（12%→6%），避免火力溢出
  - **道具运动**（所有非水晶类道具）：下落更慢、随机左右漂移且碰左右两边反弹；磁吸半径更大（170px > 水晶 110px）、拉力更强，更容易被吸到
  - 粉色 `↑`：升级套件（火力 +1 级 / 满级触发暴走，+50 分）；**其中 5% 会变为暴走道具**
  - 红橙 `S`：暴走道具（脉动强光、格外显眼）——吃到攻击等级**立刻升满级 Lv5（即暴走，限时 6s）**，+100 分
  - 青色 `◇`：量子护盾（8 秒无敌，解除时清屏敌弹）
  - 绿色 `+`：HP +40
  - 橙色 `B`：高能爆弹 +1（上限 5）
- **高能爆弹**：初始 1 枚；使用时立刻清除全部敌方弹幕并对全场敌人造成巨大伤害（4000 + 目标最大血量 10%），用于关键时刻清屏保命。
- **BOSS 击败清场**：击败任一 BOSS 时，场上所有剩余敌方单位（小怪 / 护航 / 召唤物）被强行击坠，结算画面干净无残留。
- **BOSS 战 · 旧日之歌**：**累计战斗约 60s** 后登场（宽约 60% 屏宽、小幅左右巡航、仅 1 条命）。登场演出：警报（横杠滑入 → 红区名号 → 淡出）→ 黑洞形成 → 机体浮现 → 6 部件组装；**5 种技能乱序释放**（首次必定技能 1），音核脉冲 + 声波涟漪。击败掉落 48 颗水晶 + 25% 高能爆弹 + 1 个暴走道具，随后胜利结算。
- **BOSS 战 · 暴风之眼**：第二 BOSS。第一阶段为占屏宽 80% 的**白色龙卷风暴**（俯视旋涡：多层旋臂 + 风暴眼，42000 HP），登场时风暴之风从四周汇聚成旋涡；缓慢漂移并循环释放 **5 种技能**（乱序，连中同技能弹速 ×1.4）：**风流呼啸**（屏幕右侧射出 3~4 道曲线风流，白色区域标记 1.5s 后呼啸而至，命中 30 伤害 + 击退）、**大型龙卷**（蓄力推出可击毁的龙卷，缓慢下移、360° 射风弹、碰撞 32）、**风柱连打**（连续标记 5 处垂直风柱，各 1.5s 后落下，18 伤害 + 击退）、**双臂漩涡弹幕**（4 条旋臂风弹，前半程逆时针、后半程顺时针）、**多点风弹齐射**（机体随机 9 处 + 中心瞄准玩家）。血量 70% 时在最侧边召唤一位**炮火先兆者**（固定不巡航）。被风流 / 风柱命中会被短暂击退（速度指数衰减）。
- **音乐 / 音效开关**：标题栏右侧按钮，一键静音全部 BGM 与音效；首次交互前提示「点击任意处启用背景音乐」。
- **怪物图鉴**：主界面点击图鉴入口打开，分类浏览全部敌机（名称 / 变体 / 血量 / 技能），列表卡片与详情页均以 canvas 实时渲染敌人形态预览；BOSS 页面可发起**「⚔ BOSS 试炼」**（正常战斗，敌我均会受损）或**「🔬 测试该敌人」**（敌我无敌、爆弹无限，被削至 0 可真正击坠并退出）；普通敌人页面仅「测试该敌人」。
- **暂停菜单**：按 `P` 暂停后，可选择「重新挑战」（保留当前试炼 / 测试目标重开）或「返回主界面」。
