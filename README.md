# 大无垠战机 · Big Infinity Fighter

> 当前版本：**v0.2.6**（完整变更见文末「更新日志」）

一个纯前端（HTML5 Canvas + 原生 JS ES modules）实现的雷霆战机风格小游戏 Demo，无任何外部依赖。

## 快速开始

自 v0.2.6 起游戏脚本改为 ES modules 加载，`file://` 双击打开会被浏览器 CORS 策略拦截，必须通过 HTTP 访问：

- **双击 `启动游戏.bat`**（Windows）：自动启动本地服务器并打开浏览器，关闭窗口即停止服务器；
- 或手动启动静态服务器后访问 `http://127.0.0.1:8765`：

```powershell
# PowerShell
python -m http.server 8765 --bind 127.0.0.1
# 注：不要用 5173，该端口与其它服务冲突；localhost 可能解析到 ::1，故显式绑定 127.0.0.1
```

推荐 Chrome / Edge。开发期校验：`npm run check`（顶层命名/import-export 契约静态检查）、`npm run smoke`（无头跑帧冒烟测试，无需浏览器）。

## 操作说明

| 按键 | 作用 |
|------|------|
| `W` / `A` / `S` / `D` | 上 / 左 / 下 / 右 移动战机（也支持方向键） |
| `Space` | 释放高能爆弹：立刻清除全部敌弹 + 对全场敌人造成巨大伤害（4000 + 目标最大血量10%，真实伤害），附带白闪与震屏 |
| `P` | 暂停 / 继续 |
| `R` | 立即重开 |

## 玩法要点

- **选机页面**：标题页展示战机卡片，选择后点“开始游戏”；当前可选 **混乱将至**（直射窄弹道）与 **群星之杀**（锁定光束 + 空间斩击、高额爆发，**默认机型**）。
- **僚机系统**：选机页除战机外可选**僚机**（**群星允诺** 多发散射火力覆盖 / **守愿者** 前方白盾挡弹 + 侧向扇形打击，或选“无”；**默认守愿者**）。两架僚机成对跟随主机两侧（暴走时外扩），自动朝上发射**渐变长条弹**协同输出、**不可被击中**；伤害随火力等级提升、暴走双倍、群星允诺 Lv4 额外 ×1.4；造型为“飞行武器”（双叉炮口 + 装甲弹体 + 大型后掠双尾翼 + 星核 + 推进环）。
- **主炮自动开火**，火力分 5 级，拾取粉色 `↑` 升级套件提升。
- **生命**：初始 2 条命，每条命 HP 100；血量归零掉一条命（重生后火力重置 Lv1），两条命都没了游戏结束。
- **HUD**：左上角 SCORE 面板 + 关卡 / 高能爆弹；左下角 HP 条 + 生命（♥）；右下角暴走 / 护盾倒计时读条（颜色区域随剩余时长逐渐变短）。
- **水晶**：击坠敌机大概率掉落数量不等的水晶（体型越大概率越高），垂直下坠不乱飘；每颗 +10 分，普通水晶有 0.4% 概率变为紫色**巨型水晶**（体型稍大，+500 分，相当于 50 颗）；飞机有磁吸能力，靠近自动吸附；**击败第一个 BOSS（旧日之歌）后磁吸半径永久 ×1.5**（132 → 198，重开恢复）。
- **量子护盾**：击落敌机 2% 概率掉落青色 `◇`（**蓝色敌人 6%**——幽蓝 2 类 / 蓝 4 类 / 寒霜 / 御4 / 暴风之眼；场上已有护盾道具或我方已带盾时降率 ×0.35）；拾取后 6 秒护盾加持——敌弹碰到护盾气泡即消解、免疫碰撞伤害（相当于无敌），护盾解除时清除场上一切敌弹。
- **判定点**：战机只有机身中心一个小判定点（发光白点，位于中心略下 4px），子弹 / 敌机直接命中该点才扣血，擦机身不算。
- **火力等级**（混乱将至：纯直射，攻击宽度始终控制在机身范围内，弹速快）：
  - Lv1 三射线（射速稍慢）→ Lv2 四射线 → Lv3 五射线（射速正常）→ Lv4 五射线 + 半拍后于中间补射 2 发（视觉错开，不增宽）
  - **Lv5 即暴走（限时 6s）**：十射线金色弹体（5 个位置各双发）+ 机身暴走光环，抵达时机身上方浮现“暴走”字样；暴走期间**攻速与 Lv4 相同（不再提升）、弹速大幅提升**，6s 后自动回落 Lv4（右下角读条显示剩余时长）
  - 非暴走（Lv1~Lv4）被击中：除了扣血，**累计受击两次才掉一层火力等级**（每掉一层重置计数）；**暴走（Lv5）被击中不掉层数也不计数**（护盾期间同样免疫）
  - **进入 BOSS 战会重置受击计数，且放宽为累计受击 3 次才掉一层火力**；**火力 Lv1 时对 BOSS 的武器伤害 +20%**（逆境补偿，高能爆弹不受影响）
- **HP 100**：受击后有 1.2s 无敌闪烁，不同敌机伤害不同。

**修复 · 暴风之眼区域打击"迟到命中"**

- **根因**：风波 / 风柱的命中判定含 `player.invuln <= 0`——无敌期间**跳过判定且不消耗**。玩家在无敌帧内处于打击带中时（判定点不可见、机体轮廓 40px 高，"视觉上在两条风波中间"时判定点可能已在带内），无敌在风波存续期内结束的瞬间会被**静止的"迟到的"风波命中**
- **修复**：无敌期间处于打击带内同样**消耗本次判定**（风波 / 光柱掠过，不结算也不补判）——无敌帧穿过区域打击即正常躲避
- 附带：命中判定按绘制透明度门控（`strikeVis`，渐隐至 35% 以下不再构成威胁），判定窗口与"肉眼可见"一致
