# 大无垠战机 · Great Boundless Fighter

一个纯前端（HTML5 Canvas + 原生 JS）实现的雷霆战机风格小游戏 Demo，无任何外部依赖。

## 快速开始

直接双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge）。

如需本地服务器：

```powershell
# PowerShell
cd D:\develop\Codes\great-boundless-fighter
python -m http.server 8765 --bind 127.0.0.1
# 然后浏览器访问 http://127.0.0.1:8765
# 注：不要用 5173，该端口与其它服务冲突；localhost 可能解析到 ::1，故显式绑定 127.0.0.1
```

## 操作说明

| 按键 | 作用 |
|------|------|
| `W` / `A` / `S` / `D` | 上 / 左 / 下 / 右 移动战机（也支持方向键） |
| `Space` | 释放高能爆弹：立刻清除全部敌弹 + 对全场敌人造成巨大伤害（-600 HP），附带白闪与震屏 |
| `P` | 暂停 / 继续 |
| `R` | 立即重开 |

## 玩法要点

- **选机页面**：标题页展示战机卡片，选择后点“开始游戏”；当前可选 **混乱将至**（直射窄弹道），更多战机待接入。
- **主炮自动开火**，火力分 5 级，拾取粉色 `↑` 升级套件提升。
- **生命**：初始 2 条命，每条命 HP 100；血量归零掉一条命（重生后火力重置 Lv1），两条命都没了游戏结束。
- **左上角计分表**：SCORE 面板 + HP 条 + 生命（♥）+ 火力等级。
- **水晶**：击坠敌机大概率掉落数量不等的水晶（体型越大概率越高），垂直下坠不乱飘；每颗 +10 分，普通水晶有 0.4% 概率变为紫色**巨型水晶**（体型稍大，+500 分，相当于 50 颗）；飞机有磁吸能力，靠近自动吸附。
- **量子护盾**：击落敌机 5% 概率掉落青色 `◇`；拾取后 8 秒护盾加持——敌弹碰到护盾气泡即消解、免疫碰撞伤害（相当于无敌），护盾解除时清除场上一切敌弹。
- **判定点**：战机只有机身中心一个小判定点（发光小红点），子弹 / 敌机直接命中该点才扣血，擦机身不算。
- **火力等级**（混乱将至：纯直射，攻击宽度始终控制在机身范围内，弹速快）：
  - Lv1 三射线（射速稍慢）→ Lv2 四射线 → Lv3 五射线（射速正常）→ Lv4 七射线（两条与相邻重叠，不增宽）
  - **Lv5 即暴走（限时 6s）**：十射线金色弹体（主弹 + 尾随暗弹双连发）+ 机身暴走光环，抵达时机身上方浮现“暴走”字样；暴走期间**攻速与 Lv4 相同（不再提升）、弹速大幅提升**，6s 后自动回落 Lv4（HUD 显示剩余秒数）
  - 非暴走（Lv1~Lv4）被击中：除了扣血，**累计受击两次才掉一层火力等级**（每掉一层重置计数）；**暴走（Lv5）被击中不掉层数也不计数**（护盾期间同样免疫）
- **HP 100**：受击后有 1.2s 无敌闪烁，不同敌机伤害不同。
- **四类敌机**：

  | 类别 | 名称 | 入场方式 | 血量 | 攻击行为 |
  |------|------|---------|------|---------|
  | 1类 | 侧翼艇（绿） | 侧上方斜插穿越 | 极低（一碰就碎） | 多数无攻击；少部分追踪射击，或阵亡时向下垂直射击（亡语） |
  | 2类 | 突击艇（橙） | 上方入场，短暂停顿后向下前进 | 低 | 垂直向下直射，少部分追踪射击 |
  | 3类 | 炮艇（多色变体） | 上方**快速**入场，悬停很久后缓慢下压 | 中 | 按变体分技能：**紫**＝散射+追踪交替；**红**＝火力猛（瞄准三连射/直射）；**金**＝环形弹幕密集 |
  | 3类(特殊) | 炮火先兆者（灰黑体+红核） | 上方**极慢**入场（比 2 类还慢、无 3 类高速加成），悬停位置更靠上（后排） | 中 | 不直接开火：就位后核心红色从中心扩展，4s 充满即**召唤导弹**（最多导引 3 次），随后 2s 灰黑从中心覆盖，循环；碰撞伤害仅为 2 类的 50% |
  | 4类 | 主力舰（多色变体） | 居中**快速**入场（占半屏宽），悬停很久后缓慢下压 | 高 | **红**＝双臂螺旋/9发扇形/20发环形密集弹幕；**蓝**＝更聚焦玩家的瞄准齐射+螺旋；出场及在场期间由 1/2 类护航 |
  
  - **3/4 类变体**：每次出场随机选取一种变体（颜色不同、技能不同）。其中**蓝色 4 类**出现时有 **20% 概率带护盾**：**前 6s 处于虚化状态**——机身半透明、不受任何伤害（含高能爆弹），**我方炮弹会穿过护盾打到它后面的敌人**；6s 后虚化结束方可被击破。

  - **停留与开走**：3/4 类及炮火先兆者就位后会原地开火一段时间，随后**停止攻击、以与进场相同的速度向下开走**（可能撞击我方战机）。开走计时从**就位**起算：**3 类＝30s、4 类＝40s、炮火先兆者＝16s**（约导引 3 次导弹后开走）。

  - **炮火先兆者导弹**：召唤时先锁定玩家当前水平位置，生成一条**垂直的红↔橙闪动预警线（带顶部警告图标）**；**3s 后**一枚**宽于常规子弹**的导弹从屏幕上方高速垂直下落。命中判定：**玩家 HP < 60 → 直接击杀**；**HP ≥ 60 → 失去 80% 当前血量 + 武器等级 -1**（量子护盾可消解导弹，高能爆弹可清除预警线与导弹）。

- **特殊编队**（Lv2 起约 40% 波次触发，对称/非对称混合）：
  - **镜像横排 232232**：左右对称的一排敌人（回文序列，两个 3 类移动稍慢）
  - **侧翼斜扫长队**：1 类长队从一侧斜扫到较靠下的另一侧（左右对称交叉）
  - **V 字俯冲**：2 类组成对称箭头/V 字从上方俯冲
  - **双炮艇压阵**：左右各一艘 3 类对称悬停，中间 2 类护航
  - **对角奇袭**（非对称）：一列混编沿对角线从一个上角斜插入场

- **出场节奏**：1/2 类按波次循环出场；Lv2 起 3 类按冷却出场（同屏限 1；**本局首次必定为后排“炮火先兆者”**便于识别，之后约 **30%** 为先兆者、否则普通炮艇）；Lv3 起 4 类主力舰按冷却出场（同屏限 1）。
- **关卡推进**：每 1500 分升一级，敌机 HP、生成频率递增。
- **道具掉落**：击落敌机掉落（12% 套件 / 5% 护盾 / 2.4% 加血套件）；**高能爆弹不在通用掉落池**，仅击败 4 类主力舰（7%）与 BOSS（25%）掉落
  - **动态降率**：当「场上升级套件数 + 我方当前攻击等级」等于 4 时，升级套件掉率减半（12%→6%），避免火力溢出
  - **道具运动**（所有非水晶类道具）：下落更慢、随机左右漂移且碰左右两边反弹；磁吸半径更大（170px > 水晶 110px）、拉力更强，更容易被吸到
  - 粉色 `↑`：升级套件（火力 +1 级 / 满级触发暴走，+50 分）；**其中 5% 会变为暴走道具**
  - 红橙 `S`：暴走道具（脉动强光、格外显眼）——吃到攻击等级**立刻升满级 Lv5（即暴走，限时 6s）**，+100 分
  - 青色 `◇`：量子护盾（8 秒无敌，解除时清屏敌弹）
  - 绿色 `+`：HP +40
  - 橙色 `B`：高能爆弹 +1（上限 5）
- **高能爆弹**：初始 1 枚；使用时立刻清除全部敌方弹幕并对全场敌人造成巨大伤害，用于关键时刻清屏保命。
