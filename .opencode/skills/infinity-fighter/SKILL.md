# 大无垠战机 · 项目导读与并行开发规矩

> 目标读者：新开的 AI 开发窗口。读完本页即可安全动手；细节以各权威文件为准（见下）。

## 1. 项目是什么

纯前端 **HTML5 Canvas + 原生 JS ES modules** 竖版射击游戏（雷霆战机风格），**零外部依赖、无构建步骤**。入口 `index.html`（`type="module"` 按 01→14 序号加载 `js/`），本地跑 `python -m http.server 8765 --bind 127.0.0.1` 或双击 `启动游戏.bat`（不要用 5173 端口；8765 被占时 `tools/server.py` 会自动顺延 8766+，写死端口的自动化脚本注意适配）。

## 2. 新窗口上手路径（按顺序读）

1. `AGENTS.md` —— 铁律与规矩的**权威来源**（本 Skill 是它的导读与展开，冲突时以 AGENTS.md 为准）
2. `README.md` —— 玩法/机制文案权威（前半）+ 完整更新日志（文末）

## 3. 架构地图

模块按 index.html 的 `<script type="module">` 列表顺序加载（工具以该列表为加载序唯一权威），**配置域群 01-config-{core,loadout,enemies,boss,difficulty,spawn,achievements} 内部单向依赖（按此序）、对外只出不进**。每个文件头部有契约注释：「被依赖：XX(N 名)」名单（`sync-contract.js` 自动重写）；`check-names.js` 静态强制校验 import/export 与代码一致性。

| `01-config-core` | 配置域群叶子：画布尺寸 / 演示屏坐标 / 星空 / 全部图片素材、加载器与贴图处理 |

**关键约定**：
- 共享状态新增属性必须先在 `02-core` 归域声明，不许他处裸挂
- 玩法机制描述以 `13-encyclopedia` 图鉴文案与 README 为准，改机制时同步
- 虚象/具象/真我难度分叉走 `DIFFICULTIES.<难度>.mods`（`diffMods()` 取值、缺省回退基准）；诗篇修正当前以 `isPoem()` 硬分支 + `01-config` 诗篇参数键实装（登记处：《诗篇难度修正.md》，`poem.mods` 保持 `null`，诗篇发版时统一迁移落地 mods）

## 4. 并行开发规矩（多窗口共用一个工作区）

1. **动手前先看现场**：`git status` + `git diff` + `git log --oneline -10`。工作区常有**其他窗口未提交的半成品**（历史案例：水晶 3D 改版中途 smoke 挂红）——不是你弄坏的就不要去"顺手修复"，更不要回滚别人的改动。
2. **只改你任务涉及的文件**，不重排别人正在改的区域；改完立即跑校验，别把半成品留到别人撞上。
3. **不要主动 commit**：除非用户明确要求。
4. **任务边界有疑问先问**，不要猜别的窗口在干什么然后绕着写。
5. **⛔ 严正声明：绝对禁止顺手修复其他窗口的错误**——包括但不限于语法错误、`smoke` / `check-names` 挂红、疑似 bug、可优化写法。只要不在你的任务范围内，哪怕"一行就能修好"，也**一行都不许动**：不改、不回滚、不 `git restore` / `git checkout`、不重构、不"等价改写"。**已发生真实事故**：某窗口顺手"修复"他人改动，导致文件回滚、他人修改全部丢失。正确做法只有两个：向用户口头报告，或登记到 `错误与待优化.md`。
6. **职责外错误/可优化项只登记不修**：发现不在自身职责范围内的错误或可优化项，登记到 `错误与待优化.md`（格式见该文件规则节），留给对应窗口认领。**半成品不算也不修**——若报错位置正处于其他窗口未提交的改动中（先看 `git status`/`git diff`），那是在制品：**不登记、更不修复**；等其完成后问题仍在才登记。

## 5. 铁律：速度曲线必须平滑

> 任何移动/速度改动，改完必须实际跑帧观察。

- 任何速度档位切换（入场→巡航→游走→离场、两段巡航等）必须有**指数/线性缓动过渡**（写明过渡时长或逼近率），禁止某一帧直接换目标速度
- 状态切换瞬间位置必须与前一帧**严格连续**：位置型公式（sin/cos 漂移、路径采样）在 t=0 偏移必须为 0，或做幅度缓入
- 禁止「硬 snap 吸附 + 立即套用带初值偏移的公式」（瞬跳最常见来源）
- 新增移动逻辑把「当前速度 → 新期望速度」的过渡时间写进注释（如"≈0.6s 平滑过渡"）
- 方向随机游走用**角度积分**（角速度低通平滑），不用会漂过原点的向量 OU

历史事故（勿重蹈）：法术矩阵到达突进/停滞、破片锁停 +7px 跳变、A1 两段巡航瞬变、2*7 阵型崩塌。

## 6. 铁律：脚本补丁修改文件的纪律（2026-09 事故）

用 Python/脚本对大文件做字符串补丁时：

- **find() 返回 -1 必须立即中止**（负数起点会造成 src[:-1]+INS+src[1:] 式的整文件自我复制）；每次替换必须 `assert count == 1`
- 写盘后**立刻**跑 check-names + smoke，并抽查写入点上下文
- 同一文件补丁失败 **2 次即停止**，改用编辑工具或回滚后重做——连续盲修会把小伤滚成大灾
- 含中文的查找/替换文本**禁止内联在 PowerShell 命令里**（管道转码损坏），必须写入 .py 脚本文件执行（脚本内用 unicode 转义最稳）

**补丁前三件套（缺一不许动手）**：① 先把原文件复制到工作目录外做备份；② 失败 2 次立即停下向用户报告损坏情况，**经用户同意后才能 git 回滚**——被改文件里的当日改动属于用户的任务成果，擅自回滚＝销毁用户工作；③ 回滚必须附带「丢失清单」，逐项列明待重做。

历史事故：13-encyclopedia.js 连续 5 次盲修后整文件自我复制，最终 git 回滚丢失当日全部图鉴改动。

## 8. 数值与登记纪律

- **怪物数值基准**＝桌面《怪物属性总表.xlsx》：表内数值＝当前代码权威值；改代码前先读表，改表后同步代码。**本机确切路径：`D:\Personal\Desktop\怪物属性总表.xlsx`**（2026-10-04 用户确认；本机桌面被重定向到 `D:\Personal\Desktop`，不在 `C:\Users\Administrator\Desktop`——按默认用户目录找不到 ≠ 本机无表，勿再误判）。该表只存在于用户两台工作机中的某一台——确认两台工作机桌面都没有才按口述数值实装并注明待同步，**禁止全盘搜索找表**
- **⚠️ 写表禁止硬编码列号**：每次写表前必须先读第 2 行表头，建立「单位名 → 列号」映射再写入（历史事故：列号错位一格，A1/破片/矩阵改动全写进相邻列还谎报已同步）
- **诗篇难度**：任何诗篇特殊修正（BOSS/敌人/护甲/驾驶员/掉落/刷怪节奏等一切难度分叉）必须先登记 `诗篇难度修正.md` 再实装；实装时落地 `DIFFICULTIES.poem.mods` 并同步该文档
- **⛔ 禁止擅改历史更新记录**：除非用户明确指定修改，否则任何任务**禁止改动历史更新条目**（README 文末「更新日志」等）——旧条目是既发版本的档案，不因后续机制/数值/称谓变更而回写；「当前机制」描述（README 前半 / 图鉴文案）不受此限，照常同步
- **版本号三处同步**（发版时）：① README 顶部「当前版本」② `package.json` version ③ `index.html` `.menu-version`

## 9. 命名纪律

- 编队标准名（以 `13-encyclopedia.js` 波次表为准）：**1类小队 / 22 / 1类长队 / 232232 / 双侧斜扫 / 2*7 / 紫自爆流 / 232111 / 32223**；禁用旧称（V字俯冲/对角奇袭/双炮艇压阵等）
- 难度名：**虚象 / 具象 / 真我 / 诗篇**（诗篇 = 真我之后的更高难度，wip 占位）；历史日志中 v0.3.5 更名前的「诗篇」指现「真我」
- mods 键名：语义化 + 体系前缀（`striker*` / `boss*`），勿与 `enemyHpMul` / `spawnIntervalMul` 等现有键混淆
- 改函数签名/新增顶层名必须同步该文件头部契约注释（check-names 强制）
